Tham khảo

Tài liệu của chúng tôi cung cấp mọi thứ bạn cần để tích hợp AI Thực Chiến gateway vào ứng dụng của mình.

Tuy nhiên, để hiểu sâu hơn về công nghệ nền tảng hoặc các khả năng của từng mô hình AI cụ thể, bạn có thể tham khảo tài liệu chính thức từ các nhà phát triển.

LiteLLM​

  • Tài liệu chính thức của LiteLLM: Nguồn thông tin toàn diện về công nghệ proxy đang được sử dụng, bao gồm các tính năng nâng cao như caching, fallbacks, và virtual keys.
  • Hỗ trợ API của OpenAI trên LiteLLM: Chi tiết về cách LiteLLM triển khai và hỗ trợ các endpoint theo chuẩn OpenAI.
  • Reasoning content trên LiteLLM: Cách LiteLLM chuyển reasoning_effort tới từng nhà cung cấp và trả về phần suy nghĩ.

Google​

  • Tài liệu Google AI Gemini API: Tài liệu chính thức từ Google về cách sử dụng các mô hình Gemini.
  • Tài liệu Gemini Enterprise Agent Platform (trước đây là Vertex AI): Nền tảng host Gemini, Veo và embedding trên Google Cloud.
  • Grounding with Google Search: Cách Gemini tìm kiếm web và quy định hiển thị kết quả.
  • Bảng giá Agent Platform: Giá gốc của Gemini, Veo, embedding và grounding.

OpenAI​

  • Tài liệu API OpenAI: Tài liệu chính thức cho các model gpt-*, o3, o4-mini, gpt-image-*, TTS, STT và embedding.
  • Reasoning models: Cách dùng reasoning_effort và giới hạn token cho model reasoning.
  • API reference: Chat Completions: Đặc tả tham số reasoning_effort, max_completion_tokens (thay cho max_tokens, bắt buộc với gpt-6*).
  • API reference: Responses: Đặc tả reasoning.effort và max_output_tokens.
  • Web search: Tìm kiếm web qua Responses API.

DeepSeek​

  • Tài liệu API DeepSeek: Tài liệu chính thức cho các model DeepSeek.
  • Thinking mode: Bật/tắt chế độ suy nghĩ và đọc reasoning_content.
  • Models & Pricing: Giá và tên model DeepSeek (deepseek-flash thay cho các tên cũ deepseek-v4-flash, deepseek-v4-flash-vision-exp).

Việc tham khảo các tài liệu này sẽ giúp bạn tận dụng tối đa sức mạnh của từng mô hình và giải quyết các vấn đề phức tạp hơn.
